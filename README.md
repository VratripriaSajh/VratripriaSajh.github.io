# Vratripriya Sajh — Academic Pages website

This is a Jekyll site configured to use the Academic Pages remote theme (`academicpages/academicpages.github.io`). It is based on the supplied 9-page portfolio and the requested Academic Pages structure.

## Run locally

1. Install Ruby, Bundler, and Jekyll.
2. Run `bundle install` (create a Gemfile with `gem "github-pages"` if needed for local GitHub Pages compatibility).
3. Run `bundle exec jekyll serve`.
4. Open the local URL printed by Jekyll.

## Deploy to GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root.
3. In repository Settings → Pages, select deployment from the `main` branch / root.
4. Update `_config.yml` with the final site URL and base URL if using a project repository.
